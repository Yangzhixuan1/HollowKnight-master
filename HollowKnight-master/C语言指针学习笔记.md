## 一、指针是什么

### 1. 基本定义

**指针（pointer）是一种变量，它保存一个对象或函数的地址。**

普通变量保存数据，指针变量保存地址。

```c
int num = 10;
int *p = &num;
```

可以这样理解：

- `num`：一个 `int` 变量，里面存着 `10`。
- `&num`：取得 `num` 的地址。
- `p`：一个指针变量，保存 `num` 的地址。
- `*p`：通过 `p` 保存的地址，访问对应的 `int` 对象。

### 2. 取地址与解引用

C 语言里，`&` 和 `*` 在这里有两种重要用途：

| 写法 | 名称 | 含义 |
|---|---|---|
| `&num` | 取地址 address-of | 取得变量 `num` 的地址 |
| `*p` | 解引用 dereference | 访问指针 `p` 指向的对象 |

示例：

```c
#include <stdio.h>

int main(void)
{
    int num = 10;
    int *p = &num;

    printf("%d\n", num);   // 10
    printf("%p\n", (void *)p); // 打印地址
    printf("%d\n", *p);    // 10

    *p = 20;               // 通过指针修改 num
    printf("%d\n", num);   // 20

    return 0;
}
```

**关键理解：** `p` 是地址，`*p` 是通过这个地址访问到的对象。

### 3. 指针的生活化比喻

可以把变量想成一个房间：

- 变量里的值：房间中的物品。
- 变量的地址：房间的位置。
- 指针：记录房间位置的纸条。
- `*p`：根据纸条找到房间，并查看或修改里面的物品。

这个比喻用于入门理解即可；真实的 C 指针还受到类型、对象生命周期和内存访问规则的限制。

## 二、内存与地址：指针的核心

### 1. 每个对象都有自己的地址吗？

在程序运行时，对象通常占用一段内存。对一个可寻址的对象，可以使用 `&` 取得其地址。

```c
int a = 5;
int b = 8;

int *pa = &a;
int *pb = &b;
```

`pa` 指向 `a`，`pb` 指向 `b`。它们保存的地址通常不同，但不要通过打印出来的地址推断变量在所有平台上的固定位置。

### 2. 使用 `%p` 打印地址

```c
printf("%p\n", (void *)&a);
```

使用 `%p` 输出指针地址，并将对象指针转换为 `void *`，是标准 C 中常见的写法。地址的具体显示格式由实现决定。

### 3. 指针本身也占内存

```c
int num = 10;
int *p = &num;
```

这里既有 `num` 对象，也有指针变量 `p`。`p` 自己也占用内存，并在自己的内存中保存目标地址。

```c
sizeof(num);  // num 的大小
sizeof(p);    // 指针变量 p 自身的大小
```

指针大小取决于平台和实现，不能一概认定为 4 字节或 8 字节。

### 4. 指针类型告诉编译器什么？

```c
int *p;
char *q;
double *r;
```

- `int *`：指向 `int` 对象的指针。
- `char *`：指向 `char` 对象的指针。
- `double *`：指向 `double` 对象的指针。

类型会影响解引用时如何解释内存，也会影响指针加减时跨越的元素大小。

## 三、指针类型与声明

### 1. 基本声明

```c
int *p;       // 指向 int 的指针
char *q;      // 指向 char 的指针
double *r;    // 指向 double 的指针
```

建议声明后尽快初始化，避免误用未初始化的指针。

```c
int *p = NULL;
```

`NULL` 表示空指针常量，用于表示指针当前不指向可供访问的对象。不能对空指针解引用。

### 2. 一行声明多个变量时要小心

```c
int *p, q;
```

这里只声明了 `p` 是指针，`q` 是普通 `int` 变量。

如果两个变量都需要是指针，应写成：

```c
int *p, *q;
```

### 3. 指针与目标类型必须匹配

```c
int num = 10;
int *p = &num;  // 类型匹配
```

不要随意把一种对象指针转换成另一种类型后解引用，否则可能出现对齐、类型访问或其他未定义行为问题。

### 4. `const` 与指针

`const` 放在不同位置，含义不同：

```c
const int *p1 = NULL;  // 不能通过 p1 修改它指向的 int
int *const p2 = NULL;  // p2 本身不能改为指向别处；但此例仍是空指针
const int *const p3 = NULL; // 指针和通过它访问的值都不能经由 p3 修改
```

更完整的例子：

```c
int a = 10;
int b = 20;

const int *p1 = &a;
p1 = &b;       // 可以改变 p1 的指向
// *p1 = 30;   // 不可以通过 p1 修改目标值

int *const p2 = &a;
// p2 = &b;    // 不可以改变 p2 的指向
*p2 = 30;      // 可以修改 a

const int *const p3 = &a;
// p3 = &b;    // 不可以
// *p3 = 40;   // 不可以
```

记忆方法：

- `const int *p`：指向的值不能通过 `p` 修改。
- `int *const p`：指针 `p` 本身不能改指向。
- `const int *const p`：两者都不能通过 `p` 修改。

## 四、指针与数组

### 1. 数组名在多数表达式中会转换为首元素指针

```c
int arr[4] = {10, 20, 30, 40};

int *p = arr;
```

在这个赋值表达式中，`arr` 转换为 `&arr[0]`，因此 `p` 指向数组第一个元素。

### 2. 下标与指针写法

```c
arr[2]
```

等价于：

```c
*(arr + 2)
```

如果 `p = arr`，那么 `p[2]` 也等价于 `*(p + 2)`。

```c
printf("%d\n", arr[2]);  // 30
printf("%d\n", *(arr + 2)); // 30
printf("%d\n", p[2]);    // 30
```

### 3. 指针遍历数组

```c
int arr[] = {10, 20, 30, 40};
int len = (int)(sizeof arr / sizeof arr[0]);

for (int *p = arr; p < arr + len; p++) {
    printf("%d\n", *p);
}
```

这里 `arr + len` 指向数组最后一个元素之后的位置，可以用于比较循环边界，但不能解引用。

### 4. 数组与指针并不完全相同

```c
int arr[4] = {1, 2, 3, 4};
int *p = arr;
```

- `sizeof arr` 得到整个数组占用的字节数。
- `sizeof p` 得到指针变量自身的字节数。
- `arr = p` 不合法，因为数组名不是可赋值的指针变量。
- `p = arr` 合法，因为 `p` 是普通指针变量。

### 5. 指向整个数组的指针

```c
int arr[4] = {1, 2, 3, 4};
int (*p)[4] = &arr;
```

`p` 是“指向含有 4 个 `int` 元素的数组”的指针。它和 `int *p` 不同：

- `int *p`：指向一个 `int`。
- `int (*p)[4]`：指向一个包含 4 个 `int` 的数组。

括号很重要，因为 `[]` 的优先级高于 `*`。

## 五、指针作为函数参数

### 1. 通过指针修改调用者的变量

C 语言函数参数是按值传递的。传入指针时，函数得到的是地址的副本，但可以通过这个地址访问和修改调用者的对象。

```c
#include <stdio.h>

void setValue(int *p)
{
    if (p != NULL) {
        *p = 100;
    }
}

int main(void)
{
    int num = 10;
    setValue(&num);
    printf("%d\n", num);  // 100
    return 0;
}
```

### 2. 普通参数与指针参数的区别

```c
void changeValue(int x)
{
    x = 100;   // 只修改形参副本
}

void changeByPointer(int *p)
{
    if (p != NULL) {
        *p = 100; // 修改 p 指向的对象
    }
}
```

调用 `changeValue(num)` 不会改变 `num`；调用 `changeByPointer(&num)` 则可以修改 `num`。

### 3. 数组参数为什么要传长度？

```c
void printArray(const int arr[], int len)
{
    for (int i = 0; i < len; i++) {
        printf("%d ", arr[i]);
    }
}
```

函数参数里的 `arr[]` 会调整为指针参数。函数不知道原数组的元素个数，所以需要额外传入 `len`。

### 4. 使用指针返回多个结果

指针参数常用于让函数一次修改多个结果：

```c
void calculate(int a, int b, int *sum, int *product)
{
    if (sum != NULL) {
        *sum = a + b;
    }
    if (product != NULL) {
        *product = a * b;
    }
}
```

调用示例：

```c
int sum;
int product;

calculate(3, 4, &sum, &product);
```

执行后 `sum` 为 `7`，`product` 为 `12`。

## 六、指针与字符串

### 1. 字符数组

```c
char s[] = "hello";
s[0] = 'H';  // 可以修改字符数组
```

字符数组中存放字符，并以 `'\0'` 作为 C 字符串的结束标记。

### 2. 指向字符串字面量的指针

```c
const char *p = "hello";
```

这里 `p` 指向字符串字面量。不能修改字符串字面量的内容；使用 `const char *` 可以防止通过 `p` 进行修改。

不要写成试图修改字面量的代码：

```c
/* char *p = "hello"; */
/* p[0] = 'H'; */  // 修改字符串字面量是未定义行为
```

### 3. 字符数组和字符指针的区别

```c
char a[] = "hello";
const char *p = "hello";
```

- `a` 是一个字符数组，里面存放字符串内容，可以修改数组中的字符。
- `p` 是指针变量，保存字符串字面量的地址，可以让 `p` 指向别处，但不能通过它修改字面量。
- `sizeof a` 得到字符数组大小，包含 `'\0'`。
- `sizeof p` 得到指针变量的大小。
- `strlen(a)` 得到字符串长度，不包括 `'\0'`。

## 七、动态内存管理

### 1. 为什么需要动态内存？

普通固定长度数组的大小通常在定义时确定。若需要在运行时申请一块内存，可以使用 `malloc`、`calloc` 或 `realloc`。

动态内存分配函数声明在 `<stdlib.h>` 中。

### 2. 使用 `malloc`

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;
    int *arr = malloc((size_t)n * sizeof *arr);

    if (arr == NULL) {
        return 1;  // 申请失败
    }

    for (int i = 0; i < n; i++) {
        arr[i] = i * 10;
    }

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    free(arr);   // 释放动态内存
    arr = NULL;  // 避免之后误用旧地址

    return 0;
}
```

### 3. `malloc`、`calloc`、`realloc`、`free`

| 函数 | 作用 | 注意事项 |
|---|---|---|
| `malloc(size)` | 申请指定字节数的内存 | 内容未初始化；检查是否为 `NULL` |
| `calloc(count, size)` | 申请数组空间并将分配到的字节初始化为零 | 检查是否为 `NULL` |
| `realloc(ptr, size)` | 调整已分配内存块的大小 | 先用临时指针接收结果，避免失败时丢失原指针 |
| `free(ptr)` | 释放动态分配的内存 | 释放后不能再访问原内存 |

### 4. 安全使用 `realloc`

```c
int *tmp = realloc(arr, newCount * sizeof *arr);

if (tmp != NULL) {
    arr = tmp;  // 调整成功后更新指针
} else {
    /* 调整失败时，原 arr 仍然有效，可以按需要处理 */
}
```

如果 `newCount` 来自用户输入，还应先检查它是否合理，并防止计算 `newCount * sizeof *arr` 时发生大小溢出。

### 5. 动态内存的生命周期

动态申请的内存不会因为普通局部指针变量离开作用域就自动释放。必须管理好内存的所有权：

- 申请成功后，明确哪一部分代码负责释放。
- 每块动态内存通常只应释放一次。
- 不要在释放后继续访问原内存。
- 不要对没有通过兼容方式获得的有效动态内存指针调用 `free`。

## 八、指针运算

### 1. 指针加减

若 `p` 指向数组中的一个元素：

- `p + 1`：指向下一个元素。
- `p - 1`：指向前一个元素（前提是结果仍在同一数组范围内，或指向数组末尾之后的位置规则允许的范围）。
- `p + n`：向后移动 `n` 个元素。

指针算术不是任意地址运算。运算结果必须符合 C 语言关于同一数组对象及其末尾后一位置的规则。

### 2. 指针相减

如果 `p` 和 `q` 指向同一个数组中的元素，`p - q` 得到它们之间相差的元素数量，类型为 `ptrdiff_t`。

```c
#include <stddef.h>

int arr[5];
int *p = &arr[1];
int *q = &arr[4];

ptrdiff_t distance = q - p;  // 3
```

不能把任意两个不相关对象的指针相减。

### 3. 指针比较

同一数组中的元素指针可以按位置进行比较，例如：

```c
if (p < arr + len) {
    /* p 还位于数组元素范围内 */
}
```

不要随意比较不相关对象的地址并把比较结果当作数组顺序。

### 4. `*p++`、`(*p)++` 和 `*++p`

这三种表达式含义不同：

| 表达式 | 含义 |
|---|---|
| `*p++` | 先使用当前 `p` 指向的值，再让 `p` 指向下一个元素 |
| `(*p)++` | 将 `p` 指向的元素值加 1，指针不移动 |
| `*++p` | 先让 `p` 指向下一个元素，再访问新位置的值 |

这些表达式只有在指针指向有效元素、且移动后没有越过允许范围时才能安全使用。初学时建议拆成多行写，减少阅读错误。

## 九、二级指针

### 1. 什么是二级指针？

二级指针是“指向指针的指针”。

```c
int num = 10;
int *p = &num;
int **pp = &p;
```

- `num` 是整数。
- `p` 保存 `num` 的地址。
- `pp` 保存指针变量 `p` 的地址。
- `*pp` 得到 `p`。
- `**pp` 得到 `num` 的值。

### 2. 通过二级指针修改原变量

```c
int num = 10;
int *p = &num;
int **pp = &p;

**pp = 50;
```

执行后，`num` 变成 `50`。

### 3. 为什么函数有时需要二级指针？

如果函数需要修改调用者的指针变量本身，就可以传入这个指针变量的地址。

```c
#include <stdlib.h>

int createArray(int **out, size_t count)
{
    if (out == NULL) {
        return 0;
    }

    *out = malloc(count * sizeof **out);
    return *out != NULL;
}
```

调用示例：

```c
int *arr = NULL;

if (createArray(&arr, 10)) {
    /* 使用 arr */
    free(arr);
}
```

实际项目中，还需要确保 `count * sizeof **out` 不会溢出。

### 4. 二级指针常见用途

- 让函数修改调用者的指针。
- 动态创建或更新数据结构。
- 处理字符串数组，例如 `char **argv`。
- 在链表等数据结构中修改头指针。

## 十、结构体指针

### 1. 定义结构体指针

```c
struct Student {
    int id;
    float score;
};

struct Student stu = {1, 95.5f};
struct Student *p = &stu;
```

### 2. 使用 `->` 访问成员

```c
printf("%d\n", p->id);
printf("%.1f\n", p->score);
```

`p->id` 等价于 `(*p).id`。

因为 `.` 的优先级与 `*` 的组合容易写错，所以访问指针指向的结构体成员时，通常使用 `->`。

### 3. 结构体指针注意事项

- 确保指针指向有效的结构体对象。
- 不要解引用 `NULL` 指针。
- 若结构体对象的生命周期已经结束，不要继续使用其地址。

---

## 十一、函数指针

### 1. 什么是函数指针？

函数指针保存函数的地址，可以通过它调用符合类型要求的函数。

```c
int add(int a, int b)
{
    return a + b;
}

int (*operation)(int, int) = add;
int result = operation(3, 4);  // 7
```

`int (*operation)(int, int)` 表示 `operation` 是一个指针，指向参数为两个 `int`、返回值为 `int` 的函数。

### 2. 函数指针的用途

- 让函数把另一个函数作为参数接收。
- 实现回调函数（callback）。
- 用于事件处理、排序比较函数和状态机。
- 在嵌入式程序中，可以用于组织不同操作的处理逻辑。

函数指针与普通对象指针不是同一种用途，不能随意混用。

## 十二、常见陷阱

### 1. 未初始化指针

```c
int *p;
/* *p = 10;  // 错误：p 没有指向已知的有效对象 */
```

解决办法：初始化为 `NULL`，或让它指向一个生命周期有效的对象。

### 2. 空指针解引用

```c
int *p = NULL;
/* printf("%d", *p);  // 错误 */
```

在解引用前，必须确认指针指向有效对象。

### 3. 悬空指针

```c
int *p = malloc(sizeof *p);
if (p != NULL) {
    free(p);
    p = NULL;
}
```

释放内存后，原地址不再可用于访问对象。若还有其他指针副本指向该内存，它们也会变成悬空指针。

### 4. 返回局部变量的地址

```c
int *bad(void)
{
    int x = 10;
    return &x;  // 错误：x 的生命周期结束后，地址不能继续使用
}
```

### 5. 越界指针运算

允许形成指向数组末尾后一位置的指针，但不允许解引用它。也不能任意把指针移到数组范围之外。

### 6. 忘记释放动态内存

申请成功后一直不释放，可能造成内存泄漏（memory leak）。

### 7. 重复释放

```c
free(p);
/* free(p);  // 再次释放同一块内存是不安全的 */
```

释放后可以把当前指针设为 `NULL`，但这不能自动修复指向同一内存的其他指针。

### 8. 使用 `sizeof` 误判数组长度

```c
void f(int arr[])
{
    /* sizeof arr 是指针大小，不是原数组大小 */
}
```

函数参数中的数组声明会调整为指针参数，长度应单独传入。

### 9. 混淆 `*p++` 与 `(*p)++`

前者移动指针，后者增加元素值。理解运算符优先级非常重要。

### 10. 类型不匹配和不恰当强制转换

随意将指针转换为其他类型后解引用，可能造成对齐错误、违反有效类型规则或产生未定义行为。不要把指针简单当成一个可以任意读写的整数地址。

## 十三、性能与使用场景

指针本身不是“让程序更快”的保证。它的价值在于可以间接访问对象、传递大型数据的地址、操作数组和管理动态内存。

常见用途：

- **函数修改调用者数据**：通过指针参数输出结果。
- **数组遍历**：指针可以按元素顺序移动。
- **动态内存**：在运行时申请和管理内存。
- **数据结构**：链表、树、图等结构会使用指针连接节点。
- **回调机制**：函数指针允许把操作传给其他函数。
- **嵌入式开发**：在理解目标平台、地址和访问规则后，指针可用于缓冲区和硬件接口等场景。

指针也增加了管理难度：错误的地址、越界访问、生命周期问题都可能导致程序崩溃或数据损坏。

## 十五、结合代码理解

### 1. `int *fox = malloc(...)`

这段代码涉及：

- `int *fox`：声明一个指向 `int` 的指针。
- `malloc`：申请动态内存。
- `sizeof *fox`：得到 `fox` 所指类型的大小，通常比重复写 `sizeof(int)` 更容易维护。
- `fox[i]`：通过指针访问动态分配的数组元素。
- `free(fox)`：释放申请到的动态内存。

推荐写法：

```c
size_t len = 100;
int *fox = malloc(len * sizeof *fox);

if (fox == NULL) {
    /* 处理申请失败 */
} else {
    /* 使用 fox[0] 到 fox[len - 1] */
    free(fox);
    fox = NULL;
}
```

如果 `len` 的来源不可信或可能非常大，还要检查乘法溢出和申请大小是否合理。

### 2. `bubbleSort(int arr[], int len)`

```c
void bubbleSort(int arr[], int len);
```

这里 `arr[]` 在函数参数中会调整为 `int *arr`。函数通过指针访问调用者数组里的元素，而 `len` 用于控制边界。

### 3. 归并算法中的指针思路

归并算法可以使用数组下标，也可以使用指针遍历。无论采用哪种方式，都必须确保：

- 读取的位置属于有效元素。
- 移动指针时不超出允许范围。
- 剩余元素都被复制。
- 输出数组有足够的空间。

### 4. `free(fox)` 后为什么不能继续使用？

`free` 结束了那块动态内存的分配生命周期。此后不能再通过 `fox` 读取或修改原内容，也不能再次释放同一块内存。将 `fox = NULL` 是一个有用的防误用习惯，但无法清除程序中其他指向同一块内存的指针。
